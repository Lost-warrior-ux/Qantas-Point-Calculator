# ✈️ Qantas Points Calculator

A premium, interactive, and high-performance suite of calculators designed to help travelers maximize their Qantas Frequent Flyer points. Determine how many points you can earn, flight upgrade requirements, point valuations, transfer ratios, and eligible travel destinations.

🔗 **Official Website:** [https://www.qantaspointscalculator.com/](https://www.qantaspointscalculator.com/)

---

## 🗺️ Website Directory & Page Guide

To maximize reach and indexability, here is a detailed breakdown of all tools, calculators, and educational guides available on the platform:

### 🧮 Core Tools & Interactive Calculators

* **🌐 [Qantas Points Calculator (Homepage)](https://www.qantaspointscalculator.com/)**
  The central hub of the application. Features the primary multi-function calculator that acts as a gateway to earn, use, and upgrade point estimations.
* **⚡ [Points Earn Calculator](https://www.qantaspointscalculator.com/earn)**
  A centralized portal to calculate Qantas Points and Status Credits earned across all travel partners, featuring quick links to specialized calculators.
* **🛫 [Upgrade Points Calculator](https://www.qantaspointscalculator.com/upgrade)**
  Allows passengers to enter their flight details and determine the exact number of Qantas Points needed to request a seat upgrade (from Economy to Premium Economy, Business, or First Class).
* **🎟️ [Classic Flight Rewards Portal](https://www.qantaspointscalculator.com/redeem)**
  Helps users plan points redemption for Classic Flight Rewards, calculating standard points required for domestic and international flights.
* **✈️ [Qantas Flights Earn Calculator](https://www.qantaspointscalculator.com/earn/flights)**
  A highly detailed calculator that estimates points and Status Credits earned on Qantas-operated flights based on cabin class, route, and Frequent Flyer status tier.
* **🤝 [Partner Airlines Earn Calculator](https://www.qantaspointscalculator.com/earn/partner-airlines)**
  Calculate points and status credits earned on codeshares and partner airlines including Emirates, American Airlines, Cathay Pacific, and oneworld member carriers.
* **🍊 [Jetstar Earn Calculator](https://www.qantaspointscalculator.com/earn/jetstar)**
  Tailored calculator for low-cost Jetstar flights, accounting for the specific Starter fare, Plus Bundle, and Max Bundle earning structures.
* **💰 [Points Value Calculator](https://www.qantaspointscalculator.com/points-value)**
  Determines the monetary value of Qantas Points in AUD based on redemption types (e.g., flight rewards, Points + Pay, gift cards, or shopping).
* **🔄 [Transfer Partners Calculator](https://www.qantaspointscalculator.com/transfer-partners)**
  Enables users to calculate points conversions from credit cards (Amex, ANZ, Westpac, etc.) and hotel programs into their Qantas Frequent Flyer account.
* **🗺️ ["Where Can I Go" Explorer](https://www.qantaspointscalculator.com/where-can-i-go)**
  An interactive, search-driven tool where users can enter their points balance and originating city to discover eligible destinations they can book with points.
* **🛒 [Buy Points Calculator](https://www.qantaspointscalculator.com/buy-points)**
  Evaluates whether purchasing Qantas points directly is financially viable by comparing the purchase price of points to their actual redemption value.

## 🚀 Local Development Setup

To run the application locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Lost-warrior-ux/Qantas-Point-Calculator.git
   cd Qantas-Point-Calculator/app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application locally.
